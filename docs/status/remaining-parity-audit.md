## Save regression discovered during naming integration

**P1 case-only external filenames:** Uppercase style turns `World_0_1.ldtkl` into `WORLD_0_1.ldtkl`; save publishes new output then retires the old differently-cased PathBuf. On case-insensitive macOS storage these refer to the same file, so cleanup deletes the newly-written document. Reproduced by `crates/ldtk-core/tests/naming.rs::names_are_unique_across_worlds_and_external_publication_keeps_iid_and_stub_in_sync`: save succeeds, reopen fails ENOENT. Formats author fixed cleanup using canonical paths and filesystem identity. Regression now passes together with all 8 naming tests.

## Follow-up disposition and field editing audit

The native entries above were subsequently implemented by their owners. This auditor completed navigation, naming, world hit/snap, and ruler resizing modules with targeted regressions; root/other authors implemented the Point/entity/atlas/preferences/form paths. The historical tables describe the state at discovery, not a current assertion that those implementations are absent. Whole-workspace verification and visual comparison remain separate work.

**P1 field text entry:** `FieldInstancesForm.hx:255–258` parses strings on DOM change (commit), and `FieldInstance.hx:223` applies the regex as a filter. Native `ui_fields::scalar_editor` previously submitted every keystroke: a `/^[0-9]{3}$/` field could not be entered character by character, and spaces in ordinary strings were trimmed before the next word. Actual egui pointer/keyboard events reproduced this. Field text now retains drafts until blur/Enter; multiline Enter remains a newline. Numeric keyboard edits also commit on blur/Enter, and clearing numeric text restores the field default, matching `FieldInstancesForm.hx:163,193` (`allowNull = true`). Numeric dragging remains available.

**P1 array editing:** source `FieldInstance.hx:102–115` adds null/default elements and permits removing below the minimum; `FieldInstancesForm.hx:874–882` displays an error. The strict native setter rejected the first Add for an empty minimum-three array, and UI deletion refused to cross the minimum. New `Project::set_field_editor_value` preserves schema/parse/reference checks but treats array lengths as diagnostics, while the existing strict setter remains unchanged. UI Add uses the definition default, deletion can cross the minimum, and `field_value_errors` supplies source-compatible length/required/file/reference diagnostics; panels now call these APIs.

Verification for this field change: 6 native tests using egui input events passed; core `field_edit` 24 passed, 1 historical-fixture test ignored; strict binary Clippy and targeted diff check passed. Required Point null was already accepted by core; source only shows its remove button for nullable scalar Points, so no blanket nullability relaxation was added. String regex is not a validation error in source and is not presented as one.

**P1 draft lifecycle (caught in root's final review):** original `Modal.hx:264` blurs before closing, and Editor's save/close flow closes modals before checking whether saving is needed. Buffered native fields initially exposed stale-save/clean-close and sidebar-removal paths because shortcuts run before forms. `ui_commit.rs` now defers save/request/panel/level/world/wheel actions until the old form has rendered its blur commit; raw-input interception preserves blur-before-click even for selectors rendered before that form. Text/IME/key events preceding the click are consumed before blur, and replayed input batches retain their original Ctrl/Cmd state without applying it to later input. Root wired the App action guards, raw input hook, post-dialog flush, and window-close dirty-or-draft check. Six lifecycle tests use egui input, including actual String/Int save-to-disk and reload, draft-only close prompting, panel switch, same-batch final keystrokes, and replay modifier ordering. These and the six field-input tests pass; binary and binary-test strict Clippy pass. `ui_fields` also now uses the source palette color editor supplied by formats.
