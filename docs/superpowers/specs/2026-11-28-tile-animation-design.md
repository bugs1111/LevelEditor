# LevelEditor 图块序列帧动画设计

2026-11-28 · 提交最终审核

在「图块动画」页，使用项目已有图集，为一块可铺设的图块指定一组帧。地图作者照常画水面、岩浆或自动地形，打开画布预览后，已经铺好的图块开始循环。水面可以整片同步，瀑布可以用同一块砖铺出逐行向下的高光。

## 1. 制作入口和操作

**顶栏在 T「图块集」旁新增独立的「图块动画」标签。** T 继续用于图集管理、枚举打标和自定义数据。动画页直接引用同一批项目图集。动画页用图集点选或框选动画帧，T 沿用已有的图块编辑操作。地图预览开关仍在关卡画布左侧的「显示」。Tiled 也采用同图集选帧、按帧设时长、地图单独开关预览的方式。[Tiled 官方图块动画编辑说明](https://doc.mapeditor.org/en/stable/manual/editing-tilesets/#tile-animation-editor)

1. 打开 **图块动画**，在右侧编辑区顶部用「项目图集」下拉框选择图集。左栏顶部的「＋」用于新建图块动画，搜索框可按主图块 ID 筛选当前图集的动画。切换图集时，动画列表、图集画布、帧序列和播放预览一起切换到新图集。动画列表复用图块集面板的列表模板，包括选中态、排序手柄和行菜单。行内从左到右为**拖动手柄、主图块缩略图和 ID、帧数、⋮ 功能按钮**。拖动手柄可调整当前图集内的动画顺序，点行中部可选中动画并编辑。点右端 ⋮ 打开该行动画的菜单。无枚举绑定的图集也可使用，内置只读图集沿用现有规则。
2. 点击 **新建图块动画** 后，在右上方的图集中左键单击一次，指定以后用笔刷铺到地图上的主图块。已有定义则直接打开，新主图块从空帧序列开始。首次加帧才创建项目里的动画记录。
3. 编辑当前动画时，在右侧图集上**左键单击或拖出矩形**可选中图块。松手时，仅将尚未选中的格子按从上到下、同行从左到右的顺序追加到末尾，已有帧保留顺序和时长。**右键单击或框选**可移除所选范围在当前动画中的全部帧引用，包括重复帧。拖动期间预览矩形范围。若左键从图集起拖、在帧序列的插入标记处松手，则只插入起始格的一帧，可用来重复某帧。在图集及有效插入位置之外松手则取消。
4. 编辑区上半部左侧是**帧序列**，右侧是图集。帧序列按播放顺序从上到下排列，每行左侧是缩略图，右侧是时长输入框。框内只编辑数字，单位 `ms` 固定显示在框外右侧。**单击帧缩略图**选中该帧并暂停预览。**上下拖动已有帧**调整顺序，时长随帧移动，在帧序列外松手则保持原序。建议新帧默认 **100 ms**，可统一设置全部帧时长。移除最后一帧即移除该定义，地图恢复主图块。上述编辑沿用项目的撤销、重做和保存，一次有改动的点选、框选、插入、换序或统一设置各对应一次撤销。
5. 帧序列和图集下方的 **图块预览** 默认显示一个图块。打开定义时有帧则选中第一帧，画面静止。点 **播放／暂停** 可从所选帧开始循环或停在当前画面。打开 **平铺预览** 后，将同一个图块排成 3×3 方格，用于检查上下、左右接缝。三种起播方式都使用同样的方格。「沿方向错开」的方向只决定各格的起播时间。平铺开关属于临时界面状态。整片池塘或其他组合地形可在关卡画布按实际铺设的位置预览。
6. 从第一行向下播放，末帧结束后回到第一行。动画列表的行末 ⋮ 菜单提供 **反转帧序** 和 **删除动画**。反转时每帧带着自己的时长移动。往返效果可排成 A、B、C、B。删除定义后，地图上已铺的格子显示主图块原图。列表排序、反转和删除各可一次撤销。

选中左侧动画后，右侧图集用半透明蓝色逐格标出帧序列用到的所有图块，主图块保留金色边框。主图块也用作帧时，同时显示蓝色高亮和金框。切换动画或增删帧时，高亮随当前帧序列刷新。同一格出现多次只高亮一次。再次左键选中蓝色格时保留原帧。移除操作只编辑当前动画的帧引用。

右上角的「项目图集」和下方预览区旁的动画设置都使用编辑器的属性行模板，每行从左到右依次为**属性名、帮助问号、值控件**。悬停问号显示该属性的本地化说明。动画设置中的属性名右对齐，问号与值控件各自纵向对齐。「起播方式」独占一行，选择「沿方向错开」后，依次显示「方向」和「重复格数」两行，格数的单位放在输入框后。中英文界面均使用 `ms`、`px` 等通用单位符号。按钮、整数输入和选中框沿用现有面板控件。窄面板仍能看见主图块、当前帧和播放按钮。地图上的时间、当前帧、局部预览和主图块选区均为界面状态。

## 2. 三种铺图效果

一个定义始终重复同一条序列。下表的设置只决定每个落点从循环的哪个时刻开始。

| 起播方式 | 制作时设置什么 | 地图上看到什么 |
| --- | --- | --- |
| **同步**（默认） | 设好帧和时长即可 | 同一定义的所有实例同拍。后来补画或刚滚入视野的水面直接加入当前节奏。岸线、中心若使用不同定义，需让对应画面和时长对齐。 |
| **随机起点** | 选择此项即可 | 各格从稳定的时间偏移开始，仍按原速度和顺序循环。适合独立闪烁的岩浆气泡。编辑器按关卡、图层、主图块与落格确定偏移，平移、重绘或重开项目不会重新抽取。 |
| **沿方向错开** | 选择上、下、左、右，以及「每几格重复」。建议默认向下、每 4 格，至少 2 格。 | 选向下、每 4 格时，同一行的瀑布同时亮，下一行稍后亮，第五行回到第一行的节奏。流向和帧的播放顺序可以分别修改。 |

**瀑布制作例。** 在同一列纹理上画三张图，高光在上半格停 100 ms、移到下半格停 100 ms、暗水纹停 600 ms。总周期 800 ms，选「向下，每 4 格」。从第一行高光进入上缘算起，第二、三、四行分别在 200、400、600 ms 接入，第五行在 800 ms 和第一行一起接入。想让亮纹连续穿过格线，上格最后的亮纹要碰到底边，下格第一帧要在同一横向位置从顶边接上。整块只切换明暗会呈现逐行闪亮。自动规则若上下翻转图块，也会翻转素材中的高光运动，单向瀑布应关闭规则的纵向随机翻转。

**可复现的时序。** 开启地图预览时从零开始，同一关卡各层共用时钟。平移、缩放、切层或补画都沿用该时钟。方向使用图层本地的格坐标，向右、向下为正。手绘与自动生成的每块砖均取其最终锚点 `px`，各轴除以图层的 `__gridSize` 向下取整。多格图章按每块砖的落格计算。规则像素偏移跨过格线时相位随之改变。图层整体平移时相位随图层走。对方向单位向量 `v`、重复格数 `N`、总时长 `T`，行号为 `r = mod(格坐标 · v, N)`，采样时间为 `mod(时钟 − r × T / N, T)`。取非负余数，按各帧累计时长的左闭右开区间取帧，保留分数延迟直到比较。跨关卡连续流动不在首版验收范围内。

## 3. 地图编辑和显示

关卡画布左侧「显示」工具条增加 **预览图块动画**，建议首次使用默认关闭，之后记在本机显示偏好中。关闭立即显示主图块原图，即使它与第一帧不同。开启后只播放当前关卡可见范围内本来就要绘制的手绘图块和自动图块。选中 IntGrid、实体层等也可切换。隐藏层、关闭「渲染自动图层」等原有显示设置继续生效。

照常用图层笔刷或自动规则铺主图块。笔刷、悬停预览、吸管、复制及粘贴所用的仍是主图块。在播放中的水面上吸取并补画，新格立即与水面同步。播放只替换显示的图集区域，保留图层覆盖图集、翻转、透明度、偏移、枢轴和标签。帧图像直接取同图集原图，包括本身也被用作动画主图块的格子。世界缩略图保持静态。

关闭地图预览或视野内无可见帧变化时，地图动画不申请定时重绘。有变化时按下一个可见换帧点请求重绘，沿用现有裁剪与纹理批绘。播放不写地图、不触发自动规则重算，也不进入撤销栈。

## 4. 保存和兼容

采用项目自有的一级数据结构。在主 `.ldtk` 根节点增加可选的 `levelEditor.tileAnimations`，用 `levelEditor.version` 独立标记格式。字段沿用项目的 lowerCamelCase、图块集 UID、图块整数 ID 和枚举字符串风格。示例为上面的瀑布，`baseTileId` 是地图所铺的主图块。

```json
{
  "levelEditor": {
    "version": 1,
    "tileAnimations": [
      {
        "tilesetUid": 7,
        "baseTileId": 32,
        "startMode": "Directional",
        "direction": "Down",
        "cellsPerCycle": 4,
        "frames": [
          { "tileId": 48, "durationMs": 100 },
          { "tileId": 49, "durationMs": 100 },
          { "tileId": 50, "durationMs": 600 }
        ]
      }
    ]
  }
}
```

- 每对 `(tilesetUid, baseTileId)` 只有一条定义。动画列表按 `tileAnimations` 数组中同一图块集定义的相对顺序显示和保存。帧来自该图集，顺序和重复项有意义。时长是正整数毫秒，一帧定义也有效。三种起播值为 `Sync`、`RandomStart`、`Directional`。只有 `Directional` 写 `direction`（`Up/Down/Left/Right`）和 `cellsPerCycle`。地图实例继续只保存原有图块数据，`customData` 可独立使用。
- 旧项目缺少扩展时按静态处理。含外部关卡时，定义只在主项目存一份。保存、另存、备份、恢复及三种 JSON 排版保留定义。删除最后一条时省略空动画集合，保留其他扩展数据。遇到未来版本或损坏记录时，保留原始 JSON 值并提示原因。未来版本的动画区只读，损坏记录只影响相关定义，受影响的图块按静态显示。保存、另存和普通地图编辑仍可进行。
- 复制图块集时给副本的新 UID 复制定义。删除图块集时一并移除其定义。重切或替换图集时，主图块和每一帧都参与现有「按 ID／按图集坐标／清空」操作及丢失确认。同一次撤销恢复全部引用。确认裁剪后，丢失主图块则删除整条，丢失部分帧则只移除这些帧，剩余帧保序，全部丢失才删除定义。图像临时离线时保留定义。
- 遇到无法解释的动画数据时，图集维护沿用已有的丢失确认。若重切或删除可能影响未知引用，明确提示「继续可能使保留的动画引用失效」。取消则整笔不变，确认后只改可识别的数据，未知 JSON 原样保留，一次撤销恢复图集与引用。能定位损坏记录所属图块集时只提示对应图集。复制图集遇到未知动画时注明副本只含可识别的定义。
- **原版 LDtk 另存有数据丢失边界。** 已核对 1.5.3 和本项目对照的 1.5.4 源码快照。Schema 允许追加根字段，而原版保存会从已知字段重新生成 JSON，另存后的文件会丢失动画定义。此方案以 LevelEditor 作为保存动画的编辑器。[LDtk Schema](https://github.com/deepnight/ldtk/blob/53cfd5392e7cbbf83730cba6ff0330884a6d48d8/docs/JSON_SCHEMA.json) · [原版项目读写](https://github.com/deepnight/ldtk/blob/53cfd5392e7cbbf83730cba6ff0330884a6d48d8/src/electron.renderer/data/Project.hx#L632)
- **Godot 的交接点是上述数据契约。** 导入工具据此生成可直接运行的场景，地图预览开关仅影响编辑器。Godot 原生提供同步和随机起点两种模式，确定的逐行延迟需由导入器生成相应的相位变体。本次审核范围为 LevelEditor，实际导入和重导入由导入器单独验收。[Godot 官方 TileSetAtlasSource 说明](https://docs.godotengine.org/en/stable/classes/class_tilesetatlassource.html#enum-tilesetatlassource-tileanimationmode)

## 5. 实施后的验收

| 场景 | 通过条件 |
| --- | --- |
| 制作入口 | 从顶栏打开「图块动画」，在右上角从已有动画的图集切到无动画、无枚举绑定的图集，画布显示新图集，左侧列表、帧序列和预览均为空。新建后单击主图块 A，帧序列为空。打开已有定义不会增加帧。切回 T 可直接操作 Water 标签和自定义数据，回到地图时原岸边笔刷、翻转和印章设置仍可用。 |
| 动画列表 | 选中 A，用左侧手柄交换 A、B 的位置，编辑区仍显示 A 和原有帧序，保存重开后列表顺序一致。点 B 的 ⋮ 反转帧序，仅 B 的帧序反转。删除 B 后，其地图实例显示主图块，撤销可恢复定义。 |
| 图集帧高亮 | 选中主图块 A、帧序列为 A、B、B、D 的动画，图集仅 A、B、D 三格高亮，A 带金框。从帧列表移除一个 B 时 B 仍高亮。在图集右键点 B 时，所有 B 帧一并移除，B 的高亮消失。切到另一条动画，仅显示新动画的帧高亮与主图块金框。 |
| 属性行 | 核对右上角图集选择器和下方动画设置的属性行。悬停每个问号可读到对应说明。起播方式切为「沿方向错开」时出现方向、重复格数两行，切回「同步」或「随机起点」时两行收起。 |
| 点选与拖动 | 连续两次左键点 B 得到一帧 B，从图集把 B 拖到帧列表末尾可得到 B、B。把 C 拖到两行之间，帧序列从上至下为 B、C、B。单击中间帧，在该帧的时长框输入 `240`，确认框外仍显示 `ms`，把该帧向下拖到末尾，得到 B、B、C，末帧仍为 240 ms。从图集拖到预览区、从帧列表拖到列表外松手，帧序和数量均保持原值。核对反转、删除及各次操作的撤销与重做。 |
| 左右键框选 | 从空序列逆向框选 2×2 格，得到上行左、上行右、下行左、下行右四帧。左键再次框住同一区域，帧数保持为四。右键框住右列后只剩左列两帧，一次撤销恢复四帧。移除整组后定义移除，源图集和其他动画中的引用仍可用。 |
| 静态编辑与局部播放 | 主图块和第一帧刻意选不同的图。只播放动画页预览时地图保持静态。播放中单击帧序列缩略图，预览暂停在所选帧，帧数保持原值。只开地图预览时动画页可停在选中帧。关地图开关立即还原主图块。仅切换预览后项目没有待保存修改。 |
| 单块与平铺预览 | 在帧序列和图集下方可播放、暂停，默认预览单块。打开平铺后，同步、随机起点和沿方向错开均显示 3×3 方格。把方向从向右改为向下，依次起播的位置从各列变为各行。关闭平铺回到单块，地图保留实际铺图形状。 |
| 水面与岩浆 | 手绘水面和 IntGrid 自动生成的岸边在相同时序下同拍，补画和移回视野能接拍。雨点状岩浆气泡的随机起点在不同格有变化，同一格反复平移、重开仍可复现偏移。 |
| 瀑布 | 在真实编辑器窗口并排放手绘瀑布和自动规则产生的竖向三格图章，使用相同落格与帧时长。核对横向同拍、向下每行延迟 200 ms、第五行复位，以及高光跨砖接缝。改向上后传播反向，负坐标和非整除周期也按公式通过。 |
| 保存与图集维护 | 旧静态项目、含外部关卡项目、另存和备份恢复均可重开。核对含重复帧的定义、图集复制、断图与重连、裁剪丢失确认、删除及撤销。含未知版本的项目还能编辑并保存地图，测试受影响图集重切时取消、确认、撤销三条路径，并核对未知 JSON。 |
| 画布成本 | 在同一真实窗口、同一大地图、同一缩放下对照预览开关，记录静置、平移、持续落笔的 CPU 和帧时间 P95。关闭或视野内全静态时没有动画驱动的重绘，播放时没有规则重算或逐砖定时器。 |

本文提交审核的是交互与数据契约。上表是实施后的验收标准。默认 100 ms、首次地图预览关闭、方向默认向下每 4 格，以及单文件的原版另存边界，均为本稿建议。
